Форма включена; FORM-005 принят, согласие редакции `2026-10-31`.

Для ежедневной проверки — `npm run ci:fast`; полный локальный CI — `npm run ci:full`.

Playwright Chromium (`npx playwright install chromium`). Для полного CI задайте

[CI](ops/CI.md), [backup inventory](ops/BACKUP-INVENTORY.md),

Эта инфраструктурная задача не разрешает публикацию или удаление существующих архивов.

Статический сайт на HTML5, CSS и vanilla JavaScript. Источник кода —
`AntonZemlya/dom-u-morya`; новый hosted Site и другой фреймворк не используются.
Node.js нужен только для подготовки и проверки: на хостинг передаются публичные статические файлы и PHP API; SMTP runtime и конфигурация находятся вне webroot.

## Локальная разработка и проверки

Требуются Node.js 22, Python 3.11+ локально (на Jino поддержан Python 3.6), Composer, PHP 8.4 и отдельный Playwright Chromium.

```sh
npm ci
npx playwright install chromium
npm run content
npm run check
npm test
npm run build
npm run test:dist
git diff --check
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist
```

Последняя команда открывает локальный preview готового релиза. Тесты используют
изолированный Chromium, без пользовательского Chrome. `CHROMIUM_EXECUTABLE_PATH`
допускается для отдельного тестового Chromium. Основные ширины: 1440 / 768 / 390 / 320.
Для доказательств задайте `QA_OUTPUT_DIR=/абсолютный/путь` перед `npm run test:dist`.
Снимки до/после: `node tests/capture.cjs dist /абсолютная/папка`.

## Единый источник содержимого

- `data/apartments.json`: 28 лотов, снимок **27.10.2026**, точные ID, номера,
  этажи, цены, особенности, источники и 84 ссылки на варианты планов.
- `data/plan-groups.json`: 19 групп; количество планировок не заменяет число лотов.
- `data/media.json`: 8 визуализаций и 6 фотоальбомов за апрель–сентябрь 2026.
- `data/media-provenance.json`: SHA-256, происхождение, оптимизированные варианты,
  статус прав `permission_not_verified`.
- `data/project-facts.json`, `data/conflicts.json`, `data/news.json`: проверенные
  сведения и нерешённые противоречия с источниками.
- `content-model.js`: общие функции представления для генератора и браузера.
- `scripts/generate-content.mjs`: генерирует помеченные области `index.html`,
  начальные суммы калькулятора, встроенный JSON и `scripts/content-files.mjs`.
  Встроенный JSON — производный результат, не второй вручную поддерживаемый массив.

После правки канонических данных выполните `npm run content`. `npm run check`
отклоняет устаревшие производные файлы. `npm run build` обновляет их перед сборкой.
Без JS доступны 28 карточек в четырёх раскрывающихся категориях, схемы по прямым
локальным ссылкам, восемь визуализаций, все месячные фотоальбомы и фактические тексты.
С JS работают фильтры, постепенное раскрытие списков, три вида схем, масштабирование,
клавиатура, swipe/pinch и точный перенос выбранного лота в расчёт, обращение и PDF.

### Контролируемое обновление снимка

1. Подготовьте и отдельно проверьте новый нормализованный пакет, сравните ID,
   цены, площади, этажи, группы и особенности с прошлой датой. Исчезновение карточки
   само по себе не означает продажу квартиры.
2. `python3 scripts/import-media.py /абсолютный/путь/к/пакету` копирует только
   нужные ресурсы, проверяет исходные хеши, дедуплицирует SVG и создаёт WebP.
   Нужен Pillow. Импорт использует утверждённый отбор этой редакции; смену даты,
   перечня изображений и месячных альбомов проводите осознанно в скрипте.
3. Обновите согласованные факты и дату снимка в генераторе и UI-подписях вместе
   с данными. Не меняйте дату ради видимости свежести.
4. Выполните все проверки и визуально просмотрите `dist/`. Автоматического
   скрейпера, внешнего runtime API и периодического обновления нет.

Исходные HTML застройщика, 420 лотов других проектов, полные новости и PDF-презентация
39 МБ в репозиторий и релиз не переносятся. SVG сохранены побайтно: скрытые слои
`display:none` нельзя растрировать способом, меняющим геометрию и подписи.

## Сборка и права на медиа

`scripts/release-files.mjs` задаёт явный allowlist; список новых ресурсов выводится
только из канонических ссылок, не из обхода всей папки. Проверяются локальные ссылки,
`srcset` и изображения, доступные лишь после взаимодействия. Сборка воспроизводима,
удаляет устаревшие файлы и сохраняет предыдущий полный релиз при ошибке валидации.
В `dist/` не входят исследования, тесты, отчёты или исходные JSON отдельно от HTML.

Исходные медиа и дизайн в этой задаче не меняются. Их provenance и исторические
ограничения остаются в `data/media-provenance.json`; новые публикации и изменения
прав требуют решения владельца. Исторические rollout-инструкции сохранены в `ops/ARCHIVE-FORM-001.md`,
`ops/FORM-004.md`, `ops/SMTP-GO.md` и помечены как архивные.

## Остальные границы

Production-форма отправляет заявки через принятый SMTP runtime; локальные тесты используют только loopback fake SMTP.
Ипотечная формула не изменена: единая выбранная ставка применяется ко всей сумме,
льготный лимит и условия банка требуют отдельной проверки. Нет гарантии 2% на любой
кредит. Не проверены дата передачи ключей, декларация ЕИСЖС (403 в исследовании),
права на публикацию и агентский остаток. Высота потолков противоречива в источниках;
общий числовой тезис ниже hero исключён. Срок завершения — плановый IV квартал 2027,
не дата ключей. Визуализации отделены от фотографий; октябрьская новость не выдаётся
за октябрьский фотоальбом. Карта OpenStreetMap остаётся внешним ресурсом.
