## Мониторинг и безопасность

`python3 -B scripts/check_official_prices.py --check --output report.json`

Команда только читает открытые страницы застройщика; проверяет полный набор ID, совпадение цен между общей выдачей и деталями, номер квартиры и `InStock`, цену/площадь/этаж, ограничивает подозрительные скачки. Код выхода: **0** совпадение; **2** достоверное изменение; **3** ошибка проверки.

`--apply` разрешает локальную **price-only** синхронизацию при неизменном полном наборе ID; пересчитывает групповые минимумы/максимумы и HTML. При изменении состава, несоответствии источников или иной аномалии блокирует запись. Не публикует production.

`review/price-sync-001/github-actions-daily-TEMPLATE.yml`: готовый шаблон проверки около **08:17 МСК**; пока **не активен** — подключённый GitHub OAuth-токен не имеет разрешения `workflow`. Включение требует явного разрешения владельца на изменение GitHub Actions workflows. **Production нельзя менять без отдельного owner GO**; задача предназначена для контроля и подготовки публикаций, а не автоматических деплоев.

Сведения о ценах являются публичными объявлениями застройщика, не подтверждением бронирования. `наш.дом.рф` — дополнительный источник проектной документации, а не более авторитетный источник индивидуальных текущих предложений.
