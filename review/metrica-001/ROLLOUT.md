## Rollback / state

Mutable SQLite находится вне public package и managed release backups. Она не входит
в rollback, не копируется в каждый release и не заменяется пустой базой. Никакой
деструктивной SQL-миграции. Установленный private cleanup runtime удерживать совместимым
с текущей схемой. Повторное применение этого кандидата читает ту же таблицу; отзыв
проверяется сервером. Старая база клиники никогда не используется.

Предпочтительный аварийный шаг — OFF в текущем модуле с сохранённым серверным отзывом/
очисткой. При полном откате публичных файлов предшествующий релиз вообще не содержит
аналитики; существующие browser receipts остаются серверно отозванными, а БД/namespace
сохраняются для очистки и следующей совместимой версии. Не возвращать enable-флаг из
непроверенного старого config. Откат действующего release manager проверен локальным
fixture: отзыв в SQLite, изменённый после deploy, остаётся побайтно тем же после rollback;
в release backup consent database отсутствует.

Встроенные backup Jino: покрытие/сроки пока не установлены, не объявлены отсутствующими.
Внешних шифрованных экспортов не добавлено. Никаких изменений DNS, других доменов,
Rehab Profi, рекламных кабинетов или email-retention задач.
