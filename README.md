# ЖК «Дом у моря»

Статический сайт на HTML5, CSS и vanilla JavaScript. На веб-хостинге не нужны
Node.js, npm или сборщик. Изображения, шрифты и библиотеки PDF загружаются локально;
интернет нужен для карты OpenStreetMap и внешних ссылок.

## Разработка и проверки

Требуются Node.js 20+ и Python 3. Для локального просмотра достаточно:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173/. Альтернатива: `npm run dev`.

```sh
npm ci
npx playwright install chromium
npm run check
npm test
npm run build
npm run test:dist
```

Тесты запускают отдельный Chromium без пользовательского профиля. Для имеющегося
бинарного файла можно задать `CHROMIUM_EXECUTABLE_PATH`. Проверяются три ширины,
навигация, вкладки, фильтры, lightbox/swipe, калькулятор, PDF, cookie и форма.
PDF и тестовые данные создаются во временной папке ОС и удаляются после проверки.
`test:dist` выполняет те же сценарии через HTTP-сервер именно из `dist/`.

## Релиз и публикация

`npm run build` создаёт **`dist/`** по явному списку в
`scripts/release-files.mjs`, проверяет локальные зависимости и печатает размер
и SHA-256 набора путей/содержимого. Файлы копируются без преобразований.
Повторная сборка очищает устаревший output; при ошибке проверки предыдущий полный
релиз сохраняется. В пакет входят только сайт, необходимые ресурсы и их лицензии.

Просмотр готового релиза:

```sh
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:4175/. На обычный веб-хостинг загрузите **содержимое
`dist/`** в корневой каталог сайта, сохранив структуру `assets/`. Публиковать
репозиторий целиком не требуется. `dist/` и временные результаты не коммитятся.
Сборка воспроизводима по содержимому из конкретного commit SHA.

## Обновление содержимого

- Основные тексты и секции: `index.html`; оформление и адаптивность: `styles.css`.
- Данные квартир, категории и вкладки: `script.js`. Начальные карточки и подписи
  есть также в HTML для просмотра без JavaScript; синхронизируйте оба состояния.
- Изображения: `assets/*.webp`; шрифты: `assets/fonts/`; экспорт PDF:
  `assets/vendor/`. При смене имён ресурсов обновите ссылки и список релиза.
- После изменений выполните проверки, сборку и `npm run test:dist`.

Собственный код не устанавливает cookie и не подключает аналитику;
`localStorage` хранит только выбор закрытия информационного уведомления.
Внешний ресурс в странице — встроенная карта OpenStreetMap; блокировка
взаимодействия с картой не блокирует её сетевую загрузку.

Для сохранения снимков проверки задайте `QA_OUTPUT_DIR=/абсолютный/путь` при
запуске UI-тестов. Материалы приёмки не входят в `dist/`.

В схемах квартир и галерее пока используются предусмотренные макетом заглушки.
Калькулятор применяет единую выбранную ставку ко всему кредиту; комбинированная
ипотека сверх льготного лимита требует отдельно согласованных банковских условий.
Коммерческие сведения и материалы должны быть утверждены перед публикацией.
