## Результат

Стрелки остаются на одних X/Y независимо от пропорций, разрешения и загрузки картинки, смены режима, zoom и pan. На всех четырёх проверенных viewport **максимальное смещение — 0 CSS px**, при допустимой погрешности 1 px.

Desktop использует постоянную сетку **48 px | изображение | 48 px**, с промежутками по 12 px. Вся высота боковой колонки нажимается, а пиктограмма находится в её центре. Общая ширина ограничена **1220 px**: прежние 1100 px изображения плюс две зоны и два промежутка. Кнопки не перекрывают фотографию; их края и центр не зависят от её размера. При viewport 1440 px широкое фото сохраняет ширину 1100 px.

На mobile изображению доступна вся прежняя ширина области: **358 px при viewport 390** и **288 px при viewport 320**. Поверх краёв находятся только прозрачные кнопки **44×44 px**, не сплошные боковые панели. Существующий плавный свайп остаётся основным способом навигации.

Обычное состояние — тонкие полупрозрачные светлые пиктограммы без кругов и без фона. Hover/focus увеличивают заметность и добавляют лёгкий фон. На мобильных лёгкая тень сохраняет читаемость на светлых кадрах. Толщина SVG-стрелки — 1,25 CSS px, `non-scaling-stroke`. Клавиатурный фокус виден.

## Постоянная геометрия

Внешняя CSS Grid задаёт постоянную область просмотра. Место под заголовок, виды планировки и нижние инструменты зарезервировано во всех режимах; длинная подпись прокручивается внутри своего места. Явный `minmax(0, 1fr)` ограничивает внешнюю колонку и не даёт тексту растягивать область. Поэтому появление подписи, вариантов схемы или кнопки калькулятора не сдвигает стрелки.

В `script.js` удалены `positionLightboxNavigation()`, функции планирования/сброса, связанные поля состояния, обработчики load/decode и `ResizeObserver`. Удалены CSS-переменные и классы динамического размещения. Координаты больше не вычисляются по `naturalWidth/naturalHeight` и не меняются после декодирования. Сохранён прежний resize-код, необходимый для zoom/pan и выбора srcset, без работы со стрелками. `.lightbox-track`, предзагрузка соседних кадров и механика жестов сохранены.

Координаты `getBoundingClientRect()` ниже относятся ко всей нажимаемой кнопке. На desktop она занимает всю колонку, поэтому отдельно указан центр пиктограммы по Y. Значения не изменяются между всеми пятью обязательными изображениями и дополнительными состояниями.
