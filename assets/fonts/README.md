# Локальные шрифты

Newsreader (Google Fonts v26) и Sora (v17). В `fonts.css` указаны соответствия
файлов семействам, начертаниям и весам. Лицензии OFL находятся рядом.

Эти семейства не содержат кириллических глифов: используется существующий
системный fallback. При обновлении файлов сохраняйте лицензии и актуализируйте
`fonts.css` и `scripts/release-files.mjs`.

PAGESPEED-MOBILE-001: файлы WOFF2 в `assets/performance/` являются побайтно
идентичными копиями этих шрифтов с SHA-256 в имени. Только такие адреса получают
долгий immutable-кэш. Девять исходных WOFF2 и TTF сохранены; TTF используются PDF.
`fonts.css` остаётся источником деклараций, которые `npm run content` встраивает в
четыре страницы, устраняя отдельный блокирующий запрос. Начертания, font-display
и глифы не меняются. Проверка: `node tests/performance/assets.mjs`.
