# Original typography

Unmodified Newsreader (Google Fonts v26) and Sora (v17) font files, downloaded
26 October 2026 from the exact family/weight request in the reference HTML.
`fonts.css` lists each family, style and weight. The OFL notices are included.

The source families do not provide Cyrillic glyphs. The reference's own browser
fallback is preserved; no replacement Cyrillic typeface has been introduced.
Visual comparisons run on the same Chromium/macOS font environment and route the
reference's Google Fonts request to these identical local files.
