# Локальные шрифты

Newsreader (Google Fonts v26) и Sora (v17). В `fonts.css` указаны соответствия
файлов семействам, начертаниям и весам. Лицензии OFL находятся рядом.

Эти семейства не содержат кириллических глифов: используется существующий
системный fallback. При обновлении файлов сохраняйте лицензии и актуализируйте
`fonts.css` и `scripts/release-files.mjs`.
