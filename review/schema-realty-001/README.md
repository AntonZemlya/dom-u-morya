На дату сверки у всех 28 записей `snapshot_date = 2026-10-27` и `availability_confirmed_by_agent = false`. На главной явно указана дата цен, для наличия предлагается обратиться в агентство. Поэтому граф содержит характеристики жилья и обходится без `Offer`, цены, продавца, статуса продажи, `InStock` и `Product`. Распознавание сущностей не гарантирует особого сниппета. ## Каталог и отдельные страницы

Все 28 уникальных ID в опубликованном HTML совпали с `data/apartments.json`. Квартиры сгруппированы в четыре раскрываемые категории, их площади, этажи, номера и схемы доступны без JavaScript. С JavaScript интерфейс показывает список порциями и поддерживает фильтрацию. Для поиска весь каталог имеет один canonical. Он пригоден для запросов по ЖК, а поделиться ссылкой на самостоятельную индексируемую карточку определённой квартиры сейчас нельзя.

Рекомендуем отдельные стабильные URL, если владелец готов поддерживать карточки лотов. Каждой нужны содержательный HTML с планом и характеристиками, ссылка из каталога, собственный canonical, актуальная дата и понятное состояние после продажи или снятия. Тогда можно адресовать конкретные квартиры в поиске и передавать ссылку партнёрам. Для выпуска нынешнего графа создание таких страниц необязательно.

## Яндекс Недвижимость и актуализация

YRL — отдельный XML-канал передачи объявлений на площадку. Подготовку фида имеет смысл начинать после подтверждения полномочий размещающей стороны, возможности размещения данного ЖК и регулярного источника актуальных данных. Для подготовки понадобятся ID комплекса и корпуса в Яндексе, точный адрес, состояние и срок сдачи дома, контакт продавца, даты объявлений, актуальные цены и статусы квартир, разрешённые к использованию планы и изображения. Требуется порядок обновления и удаления проданных лотов. Подача октябрьского снимка создаст риск устаревших объявлений. [Общие требования YRL](https://www.yandex.ru/support/realty/ru/feed/content-requirements) · [Требования к новостройкам](https://www.yandex.ru/support/realty-partner/ru/requirements-sale-new)

Перед выпуском владелец сверяет, что перечень 28 опубликованных карточек и их физические характеристики по-прежнему верны. Для добавления предложений нужны действующие цена, валюта, статус, продавец, его полномочия и дата проверки по каждому лоту. При актуализации сначала обновляют видимые данные.
